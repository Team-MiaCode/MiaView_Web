导出范围在进入页面、切换导出难度时初始化为目标内容的全段。PV 片段位置、试听循环和文件写入句柄属于本次会话。导出页画面设置与公共预览设置共享。

## 导出预览行为

进入导出页暂停播放，继承谱面位置并按目标内容时长限制。预览难度使用导出页选择，编辑文档保留原难度。内容终点采用 `max(音符、轨迹、可用时间、分段发射时间的末尾 + 3 秒, 音乐时长)`。

预览进度使用谱面时间：经典片头从 `-349/60` 秒开始；PV 片头从 `-664/60` 秒开始。PV 片段为 8.5 秒，试听音乐尾段至 9.75 秒，淡入 0.8 秒、淡出 3 秒。网页构建在 `build-devtools/web-config` 生成对应的公共片头配置，原生音频计划、QML 与浏览器预览使用相同参数。

输出分辨率控制预览比例，输出帧率控制导出页采样。输出统计、谱面信息、计数拍与公共画面设置随操作同步。范围选择的左右端点分别定位起点和终点，拖动选区定位起点；范围播放到终点返回起点，零秒起点结合片头返回片头开头。退出导出页保留对应谱面位置，恢复编辑难度与预览布局。

计数拍从谱面零秒按目标难度 BPM 触发；片头进入正文时沿用音频时钟，并调度零秒的首拍与音符。

成片时间沿用原生逐帧导出计划：从头导出包含 2 秒前置段与所选片头，中途导出包含 1.5 秒预载段。预览进度条右端表示内容终点。

## 验证入口

`npm run test:export-preview` 覆盖导出实时设置、负时间定位、PV 素材时间换算、范围播放、难度隔离、退出恢复与刷新持久化。`npm run test:intro-audition` 覆盖选定帧试听、循环、淡出、片段修改与独立试听接口。功能验收包含 Chromium、Firefox 和软件视频解码路径，浏览器测试使用静音启动参数。
